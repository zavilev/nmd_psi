# Code for ther paper "Estimation of splicing metrics for NMD-sensitive transcripts"

- all_nmd_inactivation_experiments.ipynb --- NMD inactivation data processing
- encode_qc.ipynb --- ENCODE RBP KD data procesing and for reproducing Figure 4C,D

- mm.py --- mixture model
